## Verification procedure (outside GitHub)

1. On a trusted machine, clone or fetch full repository history (`git fetch --all --tags --prune` and ensure the checkout is not shallow).
2. Run `npm ci --ignore-scripts && npm run check && npm test && npm audit --omit=dev --audit-level=high`.
3. Run the private-export runtime reconciliation locally; record only pass/fail and redacted diagnostics in project review notes.
4. Run `gitleaks git --source . --log-opts='--all' --redact --report-format json --report-path /path/outside/repository/gitleaks.json` with Gitleaks installed; keep reports outside the checkout.
5. Inspect Actions and rulesets directly in GitHub and record links/evidence without exposing secrets.

**Do not mark a gate complete based only on a prepared script or this document.**
